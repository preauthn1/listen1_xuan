# 使用技巧

- 上划竖屏播放栏可查看歌词
- 点击播放栏封面可查看歌词
- 竖屏时双击播放栏可播放或暂停
- 竖屏时左右滑动播放栏可切歌
- 竖屏时长按播放栏可切换播放模式
- 空格键：暂停或继续播放
- E 或句号：下一首
- Q 或逗号：上一首
- W 或 ↑：音量增大 2%
- S 或 ↓：音量减小 2%
- D 或 →：快进 3 秒
- A 或 ←：后退 3 秒
- 可拖入文件，通过 WebSocket 发送
- 安卓长按 WebSocket 客户端按钮可连接服务器
- 安卓长按 WebSocket 客户端按钮可发送剪贴板
- 使用歌曲替换功能来手动设置音源
- 本项目没有VIP破解功能
- Ciallo～ (∠・ω< )⌒★
- 在 设置 › 使用技巧 中可查看全部技巧
- 不含 FFmpeg 的版本体积更小
- 可通过 Supabase 同步播放状态
- WebSocket 服务器可传输缓存
- WebSocket 服务器可传输 Cookie
- 登录各平台账号即可获取歌单
- 播放设置可选择默认音频质量
- 可以通过 GitHub Issue 提交任何问题
- 第三方平台登录后记得点右上角保存
- “我创建的歌单”保存在本地
- 可通过 B 站弹幕生成歌词
- 可通过 B 站字幕生成歌词
- 横屏的左侧栏可调整宽度
- 设置里有在线反馈可以与我聊天
